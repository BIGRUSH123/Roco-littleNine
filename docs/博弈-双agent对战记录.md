# 双 agent 对战记录：现有 meta 队 vs 洛神杯复盘队（2026-09-21）

> 目的：让两个**没有本对话记忆**的独立 agent 在真实引擎里打一局 6v6，检验"只给队伍 + 一份职业复盘"
> 的 LLM 选手会打出什么，并与我们的规则专家（`RuleAgentV2`）对比。
> 工具：`native/tools/duel_harness.py`（动作重放式骨架，逐回合把外部指令喂进引擎）。

## 3. 分析

### 3.1 两种打法底色确实不同

| | A（现有队） | B（复盘队） |
|---|---|---|
| 出招结构（20 回合） | 技能 14（**水刃 7**、恐吓 3、械斗 2、倾泻 1、听桥 1）+ 换人 5 + 聚能 1 | 技能 12（水刃 3、**水环 2**、蝙蝠 2、力量增效/啮合传递/暴风雪/闪击/火云车/隼鳞 各 1）+ **换人 6** + 聚能 1 |
| 风格 | **单点持续压制**：T6 起锁定"圣羽翼王 + 水刃"（能耗被修正到 1）连用 7 次，把对方场上精灵一路磨死 | **轮转运营**：换人 6 次找对位，穿插防御（水环×2）与强化（力量增效），只在有把握时输出 |

B 的打法更接近复盘里鬼叔的底色（轮转 + 应对 + 强化），但**它的轮转在自己不利的速度线上没有兑现**（见 3.3）。

### 3.2 应对三角是这局唯一真正改变数值的东西

两方各成功用了两次应对，都是靠它把局势掰回来的：

| 事件 | 效果 |
|---|---|
| A 水刃（应对:状态）抓 B 的啮合传递 | B 额外 −74，圣剑-X 掉到 244（后续再也回不到正面） |
| B 水环（防御·应对:攻击）连抓 A 的水刃 2 回合 | 每回合把 ~88 砍到 **35**，救了 105/70 血量的翠顶夫人 |
| A 听桥（防御·应对:攻击）抓 B 的蝙蝠 | 把 128 砍到 **51**，并反伤 25 |
| **合计** | 3 次减伤 60%（≈省下 200+ 伤害）、1 次反制额外伤害 74 |

这正是我们规则专家的空白：本仓 `audit` 实测 `RuleAgentV2` 的出招里**防御 0.0%、状态 3.1%**，
而两个 LLM 选手是 **防御+状态 4/20 ≈ 20%**。

### 3.3 决定胜负的三处

1. **速度线不利时对攻**（T14）：B 的翠顶夫人 70HP、速度 186 对 A 的 197。它选择对攻（水刃），
   结果 A 先手把它打死 —— 这一下让 B 一次掉 2 点心力（含特性额外 −1），从此一直在"再掉 1 点就输"的悬崖上。
   复盘里反复强调速度线，B 这次违反了自己的"教案"。正确打法应是继续水环（举盾只吃 35）或换人。
2. **换人节奏被白打**：B 换人 6 次，其中 5 次换入者当场吃招（−58/−95/−74/−88/−111 ≈ **426 伤害白送**）；
   A 换人 5 次只吃到一次 −65。B 的"轮转"没有配合"对手这回合会打我"的判断。
3. **B 的强化路线收益被 A 的单点压制吃掉**：T12 的 力量增效（+100% 物攻）确实让 T15/T17 打出
   128/381 的重击，但它把强化buff传给了替补（洁癖特性），自己也因此少了一回合输出，
   最终没能把 A 的心力先打空。

### 3.4 与我们规则专家的对比（可落地的部分）

- **换人频率**：LLM 两边换人 5–6 次/20 回合（25–30%），我们的专家约 13–14%——它们是"主动轮转"，我们是"残血才换"。
- **防御/状态**：它们 20% / 我们 3%——两边都在用防御读攻击、用状态吃减伤后的窗口。
- **道具**：两边都**没用**道具（0/1、0/2）。复盘里小辞正是靠"愿力换血脉技能"赢的，
  但两个 agent 在 20 回合里一次都没想起来用——**这一层"复盘的教案"没有被 agent 内化**。
- **印记**：全程 0 层。复盘把星陨印记当核心，agent 里也没体现（B 的尖嘴狐仙 有 焚烧烙印 但没用）。


## 5. 顺带发现 → 已修复

- 一次力竭本该只扣 1 点心力（`battle_mechanics.py:293`，已用对照实验确认），
  但 T14/T17 里**掉的是 2 点**：B 的龙息帕尔带「付给恶魔的赎价」（"击败敌方精灵时，敌方额外损失1点魔力"），
  它在自己没出手的情况下让双方各多扣了 1 点。
- 复查结论：这是 `post_ko` 观察者的**视角错位** —— 默认路径会再跑一遍 `swapped_view()`，
  而 `event.target_fainted` / `event.self_koed` 是方向敏感标志，换视角后两者同时为真，
  于是「付给恶魔的赎价」在"我打赢了它"和"我被它打赢"两种条件下各触发一次（一次力竭 3 条 lives 变更）。
  修法：`vm/ctx.py::swapped_view()` 交换这两个标志；力竭路径改用 `ko_side="self"`
  并只投递给**持有者自己在场上**的观察者（`engine/battle.py::_fire_post_event`，
  `sim/battle_mechanics.py` 力竭分支）。回归测试：`backend/engine/test_traits.py`
  的三条 `blood_price` 用例（在场击杀 / 在场被击杀 / 不在场静默）。
