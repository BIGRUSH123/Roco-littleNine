# 精灵养成与 PVP 规则

## 精灵六维属性

每只精灵拥有六项基本属性：

| 属性 | 说明 |
|------|------|
| **生命** | 精灵的生命值上限 |
| **物攻** | 物理攻击伤害的基础值 |
| **魔攻** | 魔法攻击伤害的基础值 |
| **物防** | 抵抗物理攻击伤害的能力 |
| **魔防** | 抵抗魔法攻击伤害的能力 |
| **速度** | 决定回合内行动先后顺序 |

六维属性的数值受天分、性格、资质共同影响。不同精灵的种族基础值不同，同种精灵个体之间也存在差异。

## 精灵天分

天分是对精灵的综合评价。即使是相同种类的精灵，也可能拥有不同的天分。

天分受**资质**和**性格**共同影响：

- 拥有个体资质加成的属性越多，天分评级越高
- 精灵最多拥有**三条**个体资质加成的属性
- 若个体资质加成的属性与性格增益的属性重合，将额外提升天分评级

天分评级直接影响精灵在战斗中的表现上限。

## 精灵性格

每只精灵都有自己的性格。性格会影响精灵的属性——每种性格分别**增益一种属性、减益一种属性**。

详见 [[宠物性格修正表]]（含全部 30 种性格的增减对照）。

> PVP 中，性格加成值会平衡处理（见下方 [[#PVP 平衡规则]]）。

## 属性资质

属性资质由两部分构成：

| 组成部分 | 说明 |
|---------|------|
| **种族资质** | 同种精灵共享的基础资质，决定属性的基础值 |
| **个体资质** | 每只精灵独立的资质加成，属性和数值大小均有差异 |

- 最好的个体资质是**三种属性、数值为 10**
- PVP 中个体资质会自动补齐至基于基础值的最高值（见下方 PVP 平衡规则）

## 精灵特性

所有精灵都有自己的特性。大部分特性都会在战斗中**自动发动**（被动效果），不需要手动激活。

- 特性不受换人影响，是精灵的固有战斗加成
- 某些特性与特定技能配合能发挥更强的效果
- 可通过点击精灵头像查看当前特性

详见 [[特性/]]（共 174 种特性）。

## PVP 平衡规则

所有参与 PVP 对战的精灵，属性会进行平衡处理：

| 项目 | 平衡值 |
|------|--------|
| 等级 | **60 级** |
| 成长等级 | **50 级** |
| 成长星级 | **5 星** |
| 觉醒星级 | **0 星** |
| 性格加成 | **+20%**（负面效果不变） |
| 个体资质 | 全部补齐至基于基础值的**最高值** |

> 平衡处理确保 PVP 对战公平，精灵的个体差异主要体现在种族资质、血脉和技能配置上。
