## 印记效果

常驻在战场上的效果，**每一方（我方/敌方）同时只能存在1种正面印记和1种负面印记**，新印记会覆盖同类型旧印记，双方阵营印记独立计算。

| 印记 | 效果 |
| ---- | ---- |
| [[印记/减速\|减速]] | 速度-10。 |
| [[印记/光合印记\|光合]] | 每回合每层恢复1点能量。 |
| [[印记/攻击\|攻击]] | 每层使攻击技能威力+10。 |
| [[印记/蓄电印记\|蓄电]] | 攻击技能获得进发：本次威力+10。 |
| [[印记/润泽印记\|湿润]] | 每层湿润印记使所有技能能耗-1 |
| [[印记/迟缓\|迟缓]] | 后手攻击时，每层使伤害提升30%。 |
| [[印记/降临印记\|降灵]] | 精灵入场时(所有情况)，每层失去1能量。 |
| [[印记/龙式印记\|龙噬]] | 释放3能耗技能时，获得双攻+30%。 |
| [[印记/风起\|风起]] | 先手攻击时，每层使伤害提升20%，仅生效1回合。 |
| [[印记/棘刺\|棘刺]] | 精灵入场时(所有情况)，每层造成6%最大生命值伤害。 |
| [[印记/星陨印记\|星陨]] | 造成伤害后，消除所有星陨层数，每层星陨造成30威力的魔法伤害。 |
| [[印记/中毒印记\|中毒]] | 中毒效果。回合结束时，造成3%(向下取整)毒属性伤害，受到属性克制影响。 |

## 负面效果

| 效果名称 | 详情 | 独立页面 |
| :------: | :--: | :------: |
| 寄生 | 回合结束时，每层吸取6%最大生命值，换下场后清除。 | [[异常状态/寄生\|寄生]] |
| 冻结 | 每层效果冻结目标5%的最大生命值，冻结部分的生命值不可用，换下场依然存在。如果目标生命值低于总冻结生命值，则目标死亡。 | [[异常状态/冻结\|冻结]] |
| 中毒 | 中毒效果。回合结束时，造成3%(向下取整)毒属性伤害，受到属性克制影响，换下场后清除。 | [[异常状态/中毒\|中毒]] |
| 灼烧 | 回合结束时，每层灼烧造成敌方最大生命2%的火系伤害，并衰减一半层数（向上取整）。在回合中触发灼烧伤害结算时，每层灼烧造成敌方最大生命2%的真实伤害。（火系精灵免疫此效果）换下场后清除 | [[异常状态/灼烧\|灼烧]] |
| 萌化 | 变为进化链的上一阶形态，萌化后种族值也会同步降低为上一阶形态，最低形态时无法继续萌化，需要萌化获得增益的技能在最低形态时不会生效，换下场依然存在。 | [[异常状态/萌化\|萌化]] |
