# 化茧

## 效果

受到致命伤害时，获得1层萌化，并免疫此次伤害。化蝶通常有 **3 条命**（化茧层数）。

## 破解化茧

化蝶的每条命独立结算，以下手段可**一次行动移除多条命**：

| 手段 | 原理 |
|------|------|
| 冻结 | 冻结伤害超过化蝶绿血 → 一次性冻掉所有层数 |
| DOT 叠加 | 灼烧 + 中毒各自独立结算 → 回合末各扣一条命 + 攻击打死一条 = 一回合三条 |
| 翼王疾风连袭 | 一回合释放多个不同技能 → 每个技能打死一条命 |
| 酷拉过载 | 过载多次打击 → 但**总会停手在最后一条命**（疑似机制保护） |

**无效手段**：连击技能（如疾风刺）连击 100 次也只扣一条命——连击 ≠ 多次使用。
