# 增益与减益

## 概述

增益（Buff，绿色图标）和减益（Debuff，红色图标）是战斗中临时修改精灵属性的效果，显示在状态栏中。除标注"永久"之外，下场即消失。

## 减益（Debuff）

### 临时减益（下场清除）

| 效果 | 数值 | 说明 |
|------|------|------|
| 物攻等级降低 | -10% | 每层降低物理攻击力 |
| 魔攻等级降低 | -10% | 每层降低魔法攻击力 |
| 物防等级降低 | -10% | 每层降低物理防御力 |
| 魔防等级降低 | -10% | 每层降低魔法防御力 |

| 先手降低 | 先手-1 | 降低技能先手值 |
| 能耗增加 | +1 | 所有技能能耗增加 |
| 威力降低 | -10 | 技能威力减少 |

## 效果叠加与清除

- 多数增益/减益**下场即清除**
- 标记为"永久"的效果下场后保留
- 换人是清除非永久 Buff/Debuff 的主要手段
- 特性带来的效果通常挂"其他"标签，不被常规清除手段影响
