# 伤害计算公式

## 属性计算公式

PVP 对战时精灵养成被强制拉满，影响属性的只有三个因素：**种族值**、**个体值**、**性格**。

### 生命属性

```
HP = (种族值 × 2 + 个体值 × 6 + 努力值/4 + 100) × 性格修正
```

### 其他五项（物攻/魔攻/物防/魔防/速度）

```
属性 = (种族值 × 2 + 个体值 × 6 + 努力值/4 + 5) × 性格修正
```

### 参数说明

| 参数 | 说明 |
|------|------|
| 种族值 | 同种精灵同形态固定 |
| 个体值 | 初始 7~10，对战时自动平衡为初始值的 **6 倍**（即 42~60 点） |
| 性格修正 | 加项 ×1.2（+20%），减项 ×0.9（-10%），无影响项 ×1.0 |
| 努力值 | PVP 中无努力值机制，此项为 0 |

### 速度计算示例

以迪莫为例：速度种族 92，满个体(+10)，极速性格(+20%)：

```
速度 = (92 × 2 + 10 × 6 + 0 + 5) × 1.2
     = (184 + 60 + 5) × 1.2
     = 249 × 1.2
     = 298（实际值需对照公测数据）
```

> 零个体和满个体之间的速度差距 ≈ **30 点种族值**。

### 四舍五入规则

属性计算需要**两次四舍五入**：

1. 计算种族值和个体值后，四舍五入一次
2. 乘性格修正后，再四舍五入一次

**已知例外**：当种族值 105、个体值 0、无性格修正时，公式计算结果为 175.5（四舍五入应为 176），但实际为 175。除此之外未发现其他不符合公式的情况。

## 伤害计算公式

### 公式

```
伤害 = [攻击力 × 技能威力 × 克制系数 / 防御力 × 随机数 + 固定加成] × 各类倍率
```

### 系统自动计算部分

对战时技能右下角显示的威力已包含：
- **本系加成**（+25%）——精灵使用与自身属性相同的技能时，威力 × 1.25
- 基础 Buff/Debuff 修正
- 攻击/防御等级修正

### 需要手动判断的部分

| 项目 | 说明 |
|------|------|
| **先手条件加成** | 如蓝鸟特性、[[印记/风起\|风起印记]]等需先手才能触发的效果，系统不预计算 |
| **应对状态翻倍** | 攻击技能应对状态技能时威力翻倍，不计入固定威力加成 |
| **随机数** | 伤害有一定浮动范围 |

### 应对状态伤害计算

```
实际威力 = 技能威力 × 应对倍率 + 固定威力加成
```

> 例：偷袭（85 威力）应对状态时威力 3 倍。若通过盛开获得 +30 固定威力加成，实际对应威力 = 85×3 + 30 = **285**，而非 (85+30)×3。

## 一击斩杀分析

在洛克王国世界想一击秒杀对手，3 费以上的本系技能非常重要。实战中经过血量交换后，2 费本系技能收割续航更优。
