# 战斗系统基础

## 三大技能类型

洛克王国世界中所有技能分为三种类型，形成类似石头剪刀布的克制关系：

| 技能类型 | 图标 | 说明 |
|---------|------|------|
| **攻击技能** | 剑（物理）/ 法杖（魔法） | 消耗能量造成伤害 |
| **防御技能** | 盾牌 | 消耗能量减少伤害，触发额外效果 |
| **状态技能** | 三颗星 | 回能、回血、挂 Buff / Debuff、不造成直接伤害 |

### 克制关系

```
攻击 ← 克制 ← 状态
  │              │
  │ 克制         │ 克制
  ↓              ↓
防御 ←——————————→
```

- **攻击克状态**：对方使用状态技能时你打伤害，对方白白挨打
- **状态克防御**：对方使用防御技能时你放状态，防御技能无法触发效果且进入冷却，你白白获得增益
- **防御克攻击**：防御技能减伤并触发额外收益

## 能量系统

- 每只精灵默认能量上限 **10 点**，部分精灵可突破上限
- 使用技能需消耗能量，不同技能费用不同
- 能量耗尽后需使用 **聚能**（快捷键 X）回复 5 点能量
- 聚能属于**状态技能**，会被应对状态机制反制

### 费用与威力参考

| 费用 | 标准威力 |
|------|---------|
| 0 费 | 40 |
| 1 费 | 60 |
| 2 费 | 80 |
| 3 费 | 100 |
| 4 费 | 120 |
| 5 费 | 140 |

高于标准威力为超模，低于标准威力则亏模（通常附带额外效果）。

## 回合结算顺序

每回合只有三种行动：**共鸣魔法**、**更换精灵**、**使用技能**。结算时按固定优先级依次处理。

### 结算优先级

```
1. 共鸣魔法（最优先）
   ↓
2. 更换精灵
   ↓
3. 使用技能（最后结算）
```

### 共鸣魔法

共鸣魔法目前包括**愿力强化**和**净化之力**，结算时最优先。双方同时使用时，拼速度决定播片顺序（同速随机）。

- 释放共鸣魔法的回合**可以同时更换精灵**——如使用净化之力净化场上的精灵并换下场
- 净化之力播片后会立即结算入场特性，因此双开共鸣魔法时播片顺序有影响
- 经典用法：雪影冰灵首发首领化，净化之力后无论留场还是换下，后续每次上场都能享受特性入场效果

### 更换精灵

双方同时换宠时拼速度，速度快者先换（同速随机）。双换时可通过先后判断双方速度。

入场特性**实时结算**——后换上的精灵能更大程度发挥特性效果（但需注意对手换上的是否为同系克星）。

### 技能结算内部顺序

```
1. 应对成功（必定最先结算）
   ↓
2. 先手值（更高者先出）
   ↓
3. 速度（更快者先出）
   ↓
4. 同速随机
```

### 先手值

带有先手值的技能可以**无视速度**抢先出手。先手值不影响更换精灵的顺序。

| 技能 | 类型 | 说明 |
|------|------|------|
| 先发制人 | 攻击 | 对战中常见 |
| 有效预防 | 防御 | 对战中常见 |

目前影响先手值的技能和特性很少，先手值 X 高者优先。

> 实例：封印（先手值 -1）vs 对手先用防御应对成功（先手值 +1）→ 双方先手值抵消为 0，回到拼速度。

### 速度影响因素

对战中可通过技能和特性影响速度：

**直接修改速度的技能**：对速度施加固定增益或减益。

**萌化/退化**：通过降低速度种族值间接影响速度。同速度种族的精灵萌化后速度种族一般相同（如 135 速 → 108 速），但分支进化精灵受影响更大——秩序鱿墨（130 速）萌化后速度种族大降，非常怕萌化。

**特性影响速度**：

| 精灵 | 加成方式 | 计算注意 |
|------|---------|---------|
| 迪莫 | 百分比加成 | 逐层计算，每层向下取整后再乘层数 |
| 风女王 | 百分比加成 | 同上 |
| 陨星虫（国王球） | 百分比加成 | 同上 |

> 百分比速度加成计算：先算一层加成并向下取整 → 乘层数 → 加到基础速度。如迪莫两层特性 = +88 速（而非 +89 速）。

### 速度计算

速度 = (种族值 × 2 + 个体值 × 6 + 5) × 性格修正

- 满个体（+10）vs 零个体（+0）速度差距 ≈ **30 点种族值**
- 极速性格（+20%）加成显著

详见 [[伤害计算公式#速度计算示例|伤害计算公式]]。

### 同速规则

- 双方速度相同时**完全随机**决定先后
- 一旦本回合确定先后，**下回合互换**（A 先 → B 先 → A 先 → ...循环）
- **换宠洗牌**：任意一方切宠后，重新随机决定先后

### 速度线意识

PVP 中不需要记住全图鉴速度，但热门精灵的速度必须熟记：

- 面对恶魔狼 → 立刻反应它是 120 速
- 我方翼王 125 速 → 知道可以超车先动
- 最终进化速度种族基本都是 5 的倍数，同速情况很常见
- 初期可查表，多打自然记住
- 速度线统计范围通常只到 **115 极速**（115 种族 + 满个体 + 极速性格），再往下竞争不激烈

> 亲和效果（部分精灵在特定环境获得速度加成）也会影响速度，但 PVP 中不存在此效果。

## 物攻与魔攻

- **物攻**：物理攻击伤害，由物防抵挡
- **魔攻**：魔法攻击伤害，由魔防抵挡
- 六维属性：生命、物攻、魔攻、物防、魔防、速度

## 个体值

- 基础个体值为 7~10
- PVP 中个体值不补齐，星级和等级会自动补齐
- 加 10（满个体）在 60 级时为 +60
- 完美蛋默认全 +8（等同于 +48），使用金球可孵出全 +10
