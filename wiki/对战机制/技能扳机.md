# 技能扳机

## 概述

技能扳机是技能描述中常见的条件触发关键词，定义了技能额外效果何时生效。它们是理解技能机制的核心语法。

## 条件触发（若）

以"若"开头的条件，在满足时触发技能额外效果。每个条件独立判断。

| 条件 | 说明 |
|------|------|
| 敌方上回合没有受到攻击 | 判断敌方上回合是否被攻击 |
| 蓄力期间受到攻击 | 自身蓄力中被敌方攻击命中 |
| 敌方本回合更换精灵 | 敌方在本回合执行了换宠操作 |
| 先于敌方攻击 | 自身先手攻击 |
| 击败敌方 | 本次攻击将敌方击杀 |
| 使用本技能击败敌方 | 必须用当前技能完成击杀 |
| 上回合使用状态技能 | 自身上回合使用的是状态类技能 |
| 敌方能量小于等于 2 | 敌方当前能量 ≤ 2 |
| 上回合应对成功 | 自身上回合应对成功触发了效果 |
| 释放后若能量耗尽 | 技能释放后自身能量归零 |
| 敌方本回合回复生命 | 敌方在本回合有回血行为 |
| 自己生命高于 50% | 自身生命值 > 50% |
| 自己生命低于 50% | 自身生命值 < 50% |
| 敌方能量等于 0 | 敌方当前能量为 0 |
| 上回合使用攻击技能 | 自身上回合使用的是攻击技能 |
| 敌方有冻结 | 敌方身上存在冻结状态 |

## 每（重复触发）

以"每"开头的条件，在满足时累加触发，效果随次数叠加。

### 与自己相关

| 条件 | 说明 |
|------|------|
| 携带一个 0 能耗技能 | 技能栏中有零费技能 |
| 使用该技能 | 每次使用此技能 |
| 使用其他草系技能 | 每次使用其他草系技能 |
| 使用其他火系技能 | 每次使用其他火系技能 |
| 使用其他普通系技能 | 每次使用其他普通系技能 |
| 每次入场 | 每次换上场时 |
| 每次离场 | 每次离场时（包括换下、力竭） |
| 每驱散一层印记 | 每次成功清除一层印记 |
| 每次击败敌方 | 每次击杀敌方精灵 |
| 每次连击 | 每次连击攻击生效 |
| 每次应对/每成功应对 | 每次应对生效 |
| 技能位置变化时 | 技能栏位置发生变动时（传动等） |
| 每次受到伤害 | 每次被伤害命中 |
| 每失去 5% 生命 | 生命值每减少 5% |
| 被攻击一次 | 被敌方攻击命中一次 |
| 使用过一个其他系别技能 | 使用了非自身系别的技能后 |

### 与敌方相关

| 条件 | 说明 |
|------|------|
| 每失去 5% 生命 | 敌方生命值每减少 5% |
| 有一层中毒效果 | 敌方存在中毒状态 |
| 有一只力竭精灵 | 敌方有精灵已经力竭 |
| 每有一层星陨 | 敌方星陨印记层数 |
| 每有一层印记 | 敌方印记总层数 |
| 每有一层冻结 | 敌方冻结层数 |

### 与队伍相关

| 条件 | 说明 |
|------|------|
| 精灵每携带一个虫鸣 | 队伍中精灵携带虫鸣技能的数量 |

### 全局

| 条件 | 说明 |
|------|------|
| 有一层萌化 | 萌化状态层数 |

### 被奉献影响

| 条件 | 说明 |
|------|------|
| 被奉献影响 1 次 | 奉献强化叠加次数 |

## 回合结束时

回合结束阶段触发的效果。在本回合全部行动完成后、下一回合开始前结算。

## 除（排除条件）

| 条件 | 说明 |
|------|------|
| 除本回合使用的技能 | 排除当前回合使用的技能，不参与计数/条件判断 |
