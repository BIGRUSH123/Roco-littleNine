# 技能数值模型

> 技能威力与能耗之间的数学关系，用于判断技能是否"合模"。

## 基础模型

| 能耗 | 基准威力 | 递增 |
|------|---------|------|
| 0 费 | 40 | — |
| 1 费 | 60 | +20 |
| 2 费 | 80 | +20 |
| 3 费 | 100 | +20 |
| 4 费 | 120 | +20 |
| 5 费 | 140 | +20 |
| 6 费 | 150 | +10 |
| 7 费 | 160 | +10 |
| 8 费 | 171 | +11 |
| 9 费 | 181 | +10 |
| 10 费 | 191 | +10 |

> 5 费之后递增减半（每费 +10）。魔能爆上限 191，即使能量超过 10 也不会再提高。

## 连击模型

每一连击从基准威力扣 **-5**：

```
连击技能威力 = 基准威力 - 5 × 连击数
每段威力 = (基准威力 - 5 × 连击数) ÷ 连击数
```

| 技能 | 能耗 | 连击 | 计算 | 判定 |
|------|------|------|------|------|
| 落实 | 1 费 | 1 连击 | 60 - 5 = 55 | 合模 |
| 双响炮 | 1 费 | 2 连击 | (60 - 10) / 2 = 25 | 合模 |
| 流火 | 1 费 | 3 连击 | (60 - 15) / 3 = 15 | 合模 |
| 光之矛 | 3 费 | 3 连击 | (100 - 15) = 85 → 90(30×3) | **超模 +5** |
| 水花四溅 | 3 费 | 4 连击 | (100 - 20) / 4 = 20 | 合模 |
| 午夜噪音 | 4 费 | 5 连击 | (120 - 25) = 95 → 100(20×5) | **微超模** |
| 音波弹 | 3 费 | — | 实际 25 | **亏模** |
| 能量炮 | 3 费 | 2 连击 | 30×2 = 60（应 90） | **严重亏模** |

## 超模技能

连击数越高，增伤 buff 收益越大（每段都享受加成）。

| 技能 | 原因 |
|------|------|
| 光之矛 | 3 费 90 威力，比连击模型多 5，且 3 连击放大 buff |
| 撕咬 | 3 费 3 连击 + 低血量额外特效，超超模 |
| 截拳 | 打断 + 回能，武系 2 费 |

## 亏模技能

| 技能 | 原因 |
|------|------|
| 音波弹 | 3 费仅 25 威力，严重亏模 |
| 能量炮 | 3 费 60 总威力（应为 90） |

## 脱离模型

- 自己脱离（无条件）：代价 **-40 威力** 或 **-2 能量**
- 让对方脱离：代价更高
- 防御类脱离（有条件触发）：代价较低

例：闪击折返 5 费 140 → -10(2连击) = 130 → 65×2 → -40(自脱离) = 90 → 45×2 ✓

## 防御模型

每增加 1 能耗 → 减伤 +20%（无额外效果时）。推测零费防御可能为 50% 减伤。
