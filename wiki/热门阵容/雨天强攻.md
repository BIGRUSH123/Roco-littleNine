# 雨天强攻

## 核心思路

利用雨天对水系技能的50%加成，配合高速水系打手进行压制性输出。

## 核心成员

| 定位 | 精灵 | 作用 |
| ---- | ---- | ---- |
| **天气手** | — | 开场释放雨天 |
| **主力打手** | — | 本系+雨天加成进行输出 |
| **联防补位** | — | 抵抗水系弱点（草/电） |

## 联防闭环

- 天气手 → 引出 → 水系打手
- 水系打手（弱草/电）→ 联防 → 草抗/地系屏蔽
- 地系屏蔽 → 回归 → 天气手

## 操作要点

1. 保住天气手，确保雨天不断档
2. 注意对方草系/电系联防，适时切换
3. 雨天水系技能约为常规伤害的 **2.25倍**（本系1.5×天气1.5）
4. 携带一个非水系打手应对水系无效的对手

## 常见变体

- 双天气手（降低雨天断档风险）
- 雨天+电场双场地压制
