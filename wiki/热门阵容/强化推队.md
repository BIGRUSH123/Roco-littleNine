# 强化推队

## 核心思路

利用强化技能（提升攻/防/速等级）滚雪球，最终完成推队。

## 核心成员

| 定位 | 精灵 | 作用 |
| ---- | ---- | ---- |
| **强化核心** | — | 集强化、输出于一体 |
| **清场保障** | — | 清除对方反强化/状态手 |
| **联防辅助** | — | 为强化核心创造安全上场机会 |

## 联防闭环

- 利用对手换人回合 → 强化核心安全登场
- 联防清除威胁 → 强化核心重新上场
- 必要时牺牲联防精灵为强化核心换取无伤入场

## 操作要点

1. 找准时机强化，通常在对手机动性差时
2. 注意反强化技能（黑雾、清除等）
3. 强化1级=提升50%；强化2级=提升100%
4. 携带补盲技能应对抗性精灵

## 常见变体

- 物攻强化流（强化+物理爆发）
- 速度强化流（强化后先手压制）
- 双强化（攻速同升）
