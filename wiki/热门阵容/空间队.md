# 空间队

## 核心思路

利用速度反转效果，让低速高攻精灵先出手，打出爆发性伤害。

## 核心成员

| 定位 | 精灵 | 作用 |
| ---- | ---- | ---- |
| **空间手** | — | 释放戏法空间 |
| **主力炮台** | — | 低速高攻，空间下先手 |
| **空间联防** | — | 低速高耐久中转 |

## 联防闭环

- 空间手下场 → 炮台入场输出
- 空间回合结束前 → 空间手重新上场
- 利用低速互换减少被先手打击的风险

## 操作要点

1. 空间回合有限（通常5回合），需要高效利用
2. 炮台精灵速度越低越好，攻击越高越好
3. 空间手自身需要一定耐久，确保能多次上场
4. 携带后备空间手应对被率先击倒的情况

## 常见变体

- 纯低速强攻（所有成员均低速）
- 高低速混合（空间内低速输出，空间外高速收割）
