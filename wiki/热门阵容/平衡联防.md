# 平衡联防

## 核心思路

不依赖单一战术，利用属性互补和技能覆盖应对各种局面，是最稳定的体系。

## 核心成员

| 定位 | 精灵 | 作用 |
| ---- | ---- | ---- |
| **物盾** | — | 抵抗物理攻击，铺场/回复 |
| **特盾** | — | 抵抗特殊攻击，清除异常/场地 |
| **高速收割** | — | 清理残血，速度压制 |
| **突破手** | — | 打开局面，突破联防薄弱点 |
| **功能位** | — | 天气/场地/状态/钉子等辅助 |
| **反制位** | — | 针对对方核心的特定克制精灵 |

## 联防闭环

- 确保对18种属性至少各有一个**抗性位**和一个**打击位**
- 物盾 ↔ 特盾 互补形成防线
- 高速收割 ↔ 突破手 形成进攻端互补
- 功能位提供全场增益

## 操作要点

1. 平衡队核心是**预判换人**，利用属性和耐久优势
2. 每个位置都有2~3个技能，覆盖面要广
3. 不贪强化，稳扎稳打
4. 注意能量管理，避免陷入无能量可用的被动局面
5. 功能位不要贪输出，优先完成辅助任务

## 常见变体

- 偏肉联防（4防2攻）
- 偏攻联防（3防3攻）
- 消耗联防（配合钉子/天气消耗）
